# GOOD LIFE SUTRA — STANDALONE ADMIN CMS PANEL (`admin/`)

## Overview
The **Good Life Admin CMS** is a dedicated management panel built for lead generation, content management, and channel operations. It can be deployed as an independent sub-domain (e.g. `admin.goodlifesutra.com`) or run as part of the integrated Next.js application at `/admin`.

---

## Managed Modules
1. **📥 Commerce Diagnostic Leads**:
   - Filter leads by GMV band, operating intent (OEM Brand Launch / Fix & Grow / Scale Pan-India), and decision timeline.
   - Inspect full 10-step submission answers, calculated lead score, and strategic opportunity tags.
   - One-click CSV Export.

2. **📝 Insights / Blog Manager**:
   - Create, edit, publish, or draft articles.
   - Manage SEO Meta Titles, Descriptions, Categories, and Authors.

3. **🏆 Case Studies & Proof Gallery**:
   - Manage client case studies, GMV metrics, and challenge-action-result workflows.

4. **❓ FAQ Management**:
   - Add/edit FAQs across all platform sections (Homepage, B2B, Multi-Platform, OEM Incubation).

5. **👤 Author Profiles**:
   - Manage team author bios, avatars, and article attributions.

6. **📁 Media & Document Library**:
   - Asset library management for website images, PDFs, and legal factsheets.

7. **⚙️ Site Settings & 301 Redirects**:
   - Global contact phone lines, business emails, and 301 HTTP redirect rules.

---

## Standalone Deployment
```bash
# To run admin standalone:
cd website
npm run dev
# Access Admin at: http://localhost:3000/admin
```
